# parents-perspectives-parenting-education
Data and R code for analyses examining parents’ perspectives on teaching parenting and child development in U.S. high schools.

# Parents' Perspectives on Teaching Parenting and Child Development in American High Schools

This repository contains the data and R code used for the quantitative analyses reported in the manuscript **"Parents' Perspectives on Teaching Parenting and Child Development in American High Schools."**

## Files

- `teaching_parenting_analysis.R` — R code used to conduct the quantitative analyses reported in the manuscript.
- `Parent_Survey_Clean_Analytic.csv` — Clean analytic dataset used for the analyses.
